PROMPT 20 — PRIMERA GENERACIÓN REAL DE ISO MRS

Objetivo:
Preparar el entorno de prueba y ejecutar la primera generación REAL de una ISO mediante el pipeline implementado en P19.

Esta fase es principalmente de VALIDACIÓN END-TO-END.

NO añadir funcionalidades nuevas salvo correcciones necesarias descubiertas durante la prueba.

==================================================
1. PREPARACIÓN DEL ENTORNO
==================================================

Comprobar privilegios administrativos.

Si el proceso no está elevado:

ABORTAR con mensaje claro:

"Se requieren privilegios de administrador para ejecutar DISM."

No continuar.

Comprobar Windows ADK.

Buscar oscdimg.exe en las ubicaciones estándar del ADK y mediante una búsqueda segura.

Si no existe:

ABORTAR indicando:

"Windows ADK/oscdimg no está instalado."

NO descargar ni instalar software automáticamente.

==================================================
2. ISO DE PRUEBA
==================================================

Utilizar una ISO real de Windows 11 26H2 disponible.

Preferencia:

Build:
26300.9278

Si no está disponible:

utilizar la ISO más cercana disponible y documentar exactamente:

- build;
- idioma;
- arquitectura;
- edición;
- SHA256.

NO fingir que una build diferente es 26300.9278.

Preferencia:

Windows 11 Pro
Index 2
x64
es-ES

==================================================
3. INTEGRIDAD DE LA ISO
==================================================

Antes de comenzar:

calcular SHA256 de:

- ISO original;
- boot.wim original;
- install.wim original.

Registrar los valores.

Al finalizar repetirlos.

Esperado:

ISO original intacta.

==================================================
4. CONFIGURACIÓN DE PRUEBA
==================================================

Primera generación CONSERVADORA:

Perfil:
RECOMENDADO

Defender:
Mantener

Windows Update:
Mantener

Bypass

Bypass

Si faltan .NET 8.0.26 y/o PCPI reales:

NO inventarlos.

En ese caso generar la ISO sin PostInstall solamente si la configuración del pipeline permite explícitamente desactivarlo.

Documentarlo.

==================================================
5. GENERACIÓN
==================================================

Ejecutar el pipeline completo:

Validate
→ CreateWorkspace
→ CopyIsoTree
→ PrepareBootWim
→ ApplyLabConfig
→ PrepareInstallWim
→ ApplyRemovalPlan
→ PrepareAutounattend
→ PreparePostInstall
→ Validate
→ oscdimg
→ FinalValidation

No saltarse fases.

Registrar cada fase.

==================================================
6. BOOT.WIM
==================================================

Comprobar físicamente:

- Mount-Wim correcto;
- SYSTEM hive cargado;
- LabConfig aplicado;
- valores verificados;
- hive descargado;
- WIM committed;
- WIM desmontado.

Después:

Get-MountedWimInfo

debe mostrar 0 mounts MRS.

==================================================
7. INSTALL.WIM
==================================================

Comprobar físicamente:

- Pro index correcto;
- working WIM independiente;
- RemovalPlan aplicado;
- commit correcto;
- desmontaje correcto.

Si el perfil RECOMENDADO no contiene componentes concretos porque el catálogo requiere inventario previo:

respetar ese comportamiento.

NO inventar eliminaciones.

==================================================
8. AUTOUNATTEND
==================================================

Comprobar físicamente que el archivo:

- existe;
- es XML válido;
- no contiene credenciales;
- no contiene rutas del desarrollador;
- contiene configuración de cuenta local.

==================================================
9. POSTINSTALL
==================================================

Si está activado:

comprobar:

- runtime real;
- PCPI real;
- SetupComplete.cmd;
- estructura $OEM$.

Si faltan archivos reales:

NO sustituirlos.

Si PostInstall está desactivado para esta primera prueba:

registrar claramente:

[POSTINSTALL] Disabled for validation ISO

==================================================
10. OSCDIMG
==================================================

Ejecutar oscdimg real.

Registrar:

- ruta;
- versión si está disponible;
- argumentos;
- stdout;
- stderr;
- ExitCode;
- duración.

El éxito depende de:

ExitCode == 0

y de la validación posterior.

==================================================
11. ISO RESULTANTE
==================================================

Comprobar:

- archivo existe;
- tamaño > 0;
- ISO legible;
- sources/install.wim;
- sources/boot.wim;
- estructura de boot;
- autounattend si configurado;
- PostInstall si configurado.

Calcular SHA256.

Guardar metadatos:

generation-metadata.json

con:

- build;
- edición;
- arquitectura;
- idioma;
- perfil;
- InstallationOptions;
- SecurityOptions;
- fecha;
- MRS version;
- ISO SHA256.

NO incluir información personal.

==================================================
12. MOUNTS
==================================================

Al terminar:

DISM /Get-MountedWimInfo

debe confirmar:

0 mounts MRS.

Comprobar también:

- hives descargados;
- workspace consistente.

NO utilizar Cleanup-Mountpoints.

==================================================
13. PRUEBA EN VIRTUALBOX
==================================================

Si VirtualBox está disponible:

crear una VM de prueba.

Primera prueba:

- ISO MRS generada;
- configuración UEFI o BIOS documentada;
- red inicialmente desconectada si se está probando OOBE offline;
- hardware deliberadamente compatible o incompatible según la opción que se quiera comprobar.

NO intentar probar todas las cosas simultáneamente si eso impide saber qué ha fallado.

Primero comprobar:

1. ISO arranca.
2. Setup inicia.
3. Disco aparece.
4. instalación llega a OOBE.
5. cuenta local funciona.
6. Windows inicia.

Después hacer pruebas específicas de compatibilidad.

==================================================
14. PRUEBA 2 GB
==================================================

Crear una segunda VM con:

RAM:
2048 MB

Objetivo inicial:

comprobar si Setup supera el requisito de RAM.

No afirmar que Windows funciona correctamente con 2 GB.

Registrar separadamente:

Setup:
PASS/FAIL

Windows boot:
PASS/FAIL

Usabilidad:
NO EVALUAR automáticamente.

==================================================
15. PRUEBA TPM / SECURE BOOT / CPU
==================================================

Realizar pruebas independientes siempre que sea posible.

Documentar:

TPM bypass:
PASS/FAIL

Secure Boot bypass:
PASS/FAIL

CPU bypass:
PASS/FAIL

No considerar una combinación de todos los bypasses como prueba suficiente de cada uno individualmente.

==================================================
16. OOBE OFFLINE
==================================================

Si AllowOfflineOobe está activado:

desconectar red.

Comprobar si OOBE permite:

- continuar;
- crear cuenta local;
- llegar al escritorio.

Si BypassNRO no funciona en esta build:

documentarlo.

NO buscar hacks adicionales dentro de esta fase salvo corrección mínima necesaria.

==================================================
17. POSTINSTALL
==================================================

Si los archivos reales están disponibles:

comprobar:

Windows inicia
→ SetupComplete
→ .NET instalado
→ PCPI ejecutado

Si los archivos reales no están disponibles:

no declarar PostInstall validado.

==================================================
18. AUTOMATIZACIÓN
==================================================

Las pruebas visuales pueden ser manuales.

El objetivo es obtener evidencia real y reproducible.
