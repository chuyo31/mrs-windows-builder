Trabaja sobre el proyecto actual `MRS-W11PRO-by_chuyo31`.

OBJETIVO:
Crear la primera interfaz funcional de `MRS.WindowsBuilder`.

IMPORTANTE:

* No modificar los demás proyectos.
* Solo editar `MainWindow.xaml` y `MainWindow.xaml.cs` si es necesario.
* Mantener compilación limpia.
* No implementar todavía montaje DISM ni modificación de imágenes.
* Debe ser una interfaz moderna estilo Windows 11, oscura, limpia y profesional.

DISEÑO:

Ventana principal con título:
MRS Windows Builder

Estructura:

1. Barra superior

   * Logo/texto MRS
   * Título: Windows Builder
   * Estado: "Listo"

2. Panel izquierdo (Origen)

   * Botón "Seleccionar ISO"
   * Caja de texto solo lectura mostrando la ruta
   * Botón "Analizar imagen"
   * ComboBox "Edición"
   * Inicialmente deshabilitado

3. Panel central
   Tarjeta "Información de la imagen"

   Mostrar campos:

   * Sistema operativo
   * Versión
   * Build
   * Arquitectura
   * Idioma
   * Tipo de imagen (WIM/ESD)

   Todos inicialmente con "--"

4. Panel derecho
   Tarjeta "Perfiles"

   Tres botones grandes:

   * NORMAL
   * LIGHT
   * MEDIUM

   Deben ser visuales únicamente.
   Al pulsarlos marcar el seleccionado.

5. Parte inferior
   Área tipo consola/log con fondo negro.
   Debe mostrar:
   [INFO] MRS Windows Builder iniciado
   [INFO] Esperando seleccionar una ISO

FUNCIONALIDAD:

* El botón Seleccionar ISO abre OpenFileDialog.

* Solo permitir `.iso`

* Al elegir una ISO mostrar la ruta.

* Activar el botón Analizar imagen.

* El botón Analizar imagen todavía NO analiza realmente:
  escribir en el log:
  [INFO] Analizando imagen...
  [INFO] Función pendiente de conectar con MRS.ImageEngine

* Los perfiles NORMAL/LIGHT/MEDIUM deben poder seleccionarse visualmente.

* Añadir un botón inferior derecho:
  "Continuar"
  inicialmente deshabilitado.

ESTILO:

* Dark theme.
* Azul eléctrico como color principal.
* Bordes redondeados.
* Tarjetas con sombras suaves.
* Fuente Segoe UI.
* Diseño responsive dentro de la ventana.
* Tamaño inicial aproximado 1200x720.
