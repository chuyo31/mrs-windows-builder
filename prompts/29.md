# P29 — Corrección real de OOBE Offline + Cuenta Local

OBJETIVO:
Corregir exclusivamente el flujo OOBE de la ISO MRS.

La prueba real de P28 ha confirmado:

FUNCIONA:
- TPM bypass
- Secure Boot bypass
- CPU bypass
- RAM bypass con 2 GB
- LabConfig en boot.wim Index 1
- LabConfig en boot.wim Index 2
- BypassNRO en boot.wim Index 2

NO FUNCIONA:
- OOBE offline
- evitar pantalla "Vamos a conectarte a una red"
- creación automática de cuenta local

La VM utilizada para la prueba:
- EFI/UEFI: ON
- TPM: OFF
- Secure Boot: OFF
- CPU: 2
- RAM: 2 GB

La ISO llegó correctamente hasta OOBE, por lo que NO tocar la implementación de LabConfig ni los bypass hardware que ya funcionan.

==================================================
1. AUDITAR EL AUTOUNATTEND ACTUAL
==================================================

Revisar:
- AutounattendGenerator
- InstallationOptions
- IsoGenerationPipeline
- cualquier código que copie/autoinstale autounattend.xml.

El XML actual contiene:

<settings pass="specialize">
  Microsoft-Windows-Deployment
  RunSynchronousCommand
  reg add HKLM\SYSTEM\Setup\OOBE /v BypassNRO /t REG_DWORD /d 1 /f
</settings>

y:

<settings pass="oobeSystem">
  Microsoft-Windows-Shell-Setup
  OOBE
  HideEULAPage=true
  HideOEMRegistrationScreen=true
  HideOnlineAccountScreens=true
  HideWirelessSetupInOOBE=true
  ProtectYourPC=3
  NetworkLocation=Home

  LocalAccounts
    LocalAccount
      Name=Usuario
      Group=Administrators
</settings>

En la prueba real, Windows llegó a:

"Vamos a conectarte a una red"

por lo que el bloque actual de specialize NO está consiguiendo el comportamiento esperado.

NO asumir que el XML es aplicado simplemente porque existe en la raíz del ISO.

==================================================

Si técnicamente es necesario, aplicar:

HKLM\SYSTEM\Setup\OOBE
    BypassNRO = DWORD 1

al Windows instalado durante la preparación offline de install.wim.

IMPORTANTE:
- utilizar los mecanismos existentes de OfflineRegistryEditor;
- no duplicar lógica innecesariamente;
- mantener idempotencia;
- montar el índice correcto de install.wim;
- modificar;
- verificar;
- desmontar correctamente.

No modificar la imagen fuente original.
Trabajar únicamente sobre la working image que ya utiliza el pipeline.
