PROMPT 07 — REMOVAL ENGINE SEGURO

OBJETIVO:

Implementar el primer RemovalEngine real de MRS Windows Builder.

Esta es la primera fase en la que MRS puede modificar una imagen Windows.

REGLA FUNDAMENTAL:

NUNCA modificar directamente el install.wim/install.esd de la ISO original.

La imagen original debe permanecer intacta.

El trabajo debe realizarse sobre una COPIA DE TRABAJO.

Arquitectura:

ISO ORIGINAL
    ↓
WORKING IMAGE
    ↓
Mount-Wim /ReadWrite
    ↓
RemovalPlan
    ↓
RemovalEngine
    ↓
DISM
    ↓
Validación
    ↓
Commit solamente si TODO es correcto

Si existe cualquier error durante la ejecución:

    ↓
Unmount /Discard

NO conservar una imagen parcialmente modificada.

2. RESPONSABILIDAD
==================================================

RemovalEngine recibe:

- imagen de trabajo.
- índice.
- RemovalPlan.
- workspace.

Y ejecuta las acciones permitidas.

NO debe clasificar componentes.

NO debe decidir qué proteger.

NO debe crear el RemovalPlan.

NO debe modificar la selección del usuario.

Su función es:

VALIDAR → MONTAR → EJECUTAR → VALIDAR → COMMIT/DISCARD

7. PRE-FLIGHT
==================================================

Antes de modificar:

2. comprobar que plan.IsValid == true.
3. comprobar que existe WorkingWim.
4. comprobar índice.
5. comprobar espacio disponible.
6. ejecutar:

7. Si existen montajes propios abandonados:
   recuperarlos de forma segura.

==================================================
8. MONTAJE READWRITE
==================================================

Montar:

DISM /English /Mount-Wim
    /WimFile:"<WorkingWim>"
    /Index:<index>
    /MountDir:"<workspace>\mount"

IMPORTANTE:

NO utilizar /ReadOnly.

La imagen de trabajo es la única que puede modificarse.


==================================================

- acción coincide con RemovalMode.
- target no está vacío.

Si cualquiera falla:

NO ejecutar la acción.

Marcarla como error.

Abortar la ejecución.

18. ORDEN DE EJECUCIÓN
==================================================

Si el plan contiene conflictos:

no ejecutar.


==================================================
19. ABORTAR SI FALLA
==================================================

Si una acción devuelve:

ExitCode != 0

hacer:

1. registrar error.
2. marcar RemovalExecutionItem como Failed.
3. NO ejecutar acciones posteriores.
4. Unmount /Discard.
5. verificar Get-MountedWimInfo.
6. conservar workspace.
7. devolver resultado Failed.


Esto proporciona una especie de comportamiento transaccional:

TODO OK
    → Commit

CUALQUIER ERROR
    → Discard


==================================================
20. COMMIT
==================================================

Solo si:

- todas las acciones han terminado correctamente.
- no hay errores.
- no se canceló.
- la imagen sigue montada correctamente.

entonces:

DISM /English
    /Unmount-Wim
    /MountDir:"<mount>"
    /Commit


Después:

Get-MountedWimInfo

Debe confirmar:

no queda nuestro montaje.
